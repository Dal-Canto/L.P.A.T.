## Non Sai Dove Iniziare?

### 🎯 Per Adolescenti (Qualsiasi Livello di Coding)

**Opzione 1: Test & Feedback**
- Scarica il repo, esegui un template (vedi README)
- Scrivi su Discussions: "Ho testato X, ecco cosa è successo"
- Feedback onesto = contributo valido

**Opzione 2: Scrivi un Template**
- Pensa a una tua routine / goal
- Scrivi in formato `.detox` (vedi `templates/` per esempi)
- Apri issue: "Ho scritto un template per [cosa]"

**Opzione 3: Racconti la Tua Storia**
- "Ho usato L.P.A.T. per 1 settimana, ecco cosa è cambiaTo"
- Crea discussion nel repo o scrivi post che linkhi

## Come Iniziare (Passo per Passo)

### 1️⃣ Fork e Clone
```bash
git clone https://github.com/YOUR-USERNAME/L.P.A.T.
cd L.P.A.T.
```

### 2️⃣ Crea un Branch
```bash
git checkout -b feature/tuo-nome
# Esempi: feature/template-matematica, fix/typo-readme, docs/guida-beginners
```

### 3️⃣ Fai i Tuoi Cambiamenti
```bash
# Aggiungi file, modifica codice, etc.
git add .
git commit -m "Descrizione chiara di cosa hai fatto"
git push origin feature/tuo-nome
```

### 4️⃣ Apri una Pull Request
- Vai su https://github.com/Dal-Canto/L.P.A.T./pulls
- Click "New Pull Request"
- Spiega **brevemente** cosa hai fatto e perché

### 5️⃣ Aspetta Feedback
- Ti risponderemo in max 48h
- Non è critica personale, è improvement
- Quando approviamo, merge e **sei nei contributor!**

## Code Style & Linee Guida

### Python
- Python 3.8+
- PEP 8 (flake8)
- Docstring per funzioni importanti
- Usa type hints dove possibile

### Template `.detox`
```detox
# Formato chiaro e leggibile
program: nome_qui
duration: XYmin / XYh / all_day
apps_blocked: [app1, app2]
# Commenti ammessi con #
```

### Documentazione
- Italiano preferito (ma accettiamo anche English)
- Markdown formattato
- Esempi reali, non astratti

## Domande Frequenti

**D: Non conosco la grammatica Lark, posso comunque aiutare?**
R: Sì! Testa il progetto, scrivi template, dai feedback. Non serve saper programmare.

**D: Quanta esperienza di Python mi serve?**
R: Da "ciao mondo" a "conosco bene". I task sono divisi per livello.

**D: Mi piacerebbe lavorarci full-time in futuro?**
R: Fantastico! Contribuisci adesso, dimostra commitment. Pensiamo sempre a partnership/funding.

**D: Posso aggiungere una feature grande?**
R: Apri **issue first** per discutere. Evita lavoro wasted.

**D: Quanto tempo ci vuole a fare un contributo?**
R: Da 15 minuti (typo fix) a 8 ore (feature media). Scegli il tuo livello.
