# CONTRIBUTING

Grazie per voler contribuire a L.P.A.T.!

Linee guida rapide:
- Apri issue per bug o richieste di feature.
- Proposte di nuovi template: crea una PR con un file YAML in /templates/ e una breve descrizione.
- Per modifiche al runtime, apri PR e assicurati che i test (quando presenti) passino.
