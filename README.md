# 📱➡️📚 L.P.A.T. — Distacco dal Telefono (Non è una Prigione)

> **Un linguaggio di programmazione che ti aiuta a staccarti dal telefono — *liberamente*, *in sicurezza*, *condividibile*.**

Scritto per adolescenti, genitori, insegnanti, chiunque voglia un vero digitale detox senza blocchi forzati.

---

## 🎯 Perché L.P.A.T.?

### Il Problema 📵
- ❌ Ti dici "non uso il telefono", poi passa un'ora
- ❌ App di blocco ti sentono controllato, non motivato
- ❌ Genitori/insegnanti non sanno come aiutare davvero
- ❌ Promesse "domani smetto" non funzionano

### La Soluzione ✅
L.P.A.T. è un **linguaggio dichiarativo** che ti permette di:
- 📋 **Scrivere le tue regole** in modo semplice (non codice, è intuitivo)
- 🤝 **Condividere impegni** con amici/genitori (accountability)
- 🔒 **Trasparenza totale** — tu sai esattamente cosa succede
- 🎓 **Imparare logica programmatica** mentre ti liberi dal telefono

---

## 🚀 Cominci in 30 Secondi

```bash
git clone https://github.com/Dal-Canto/L.P.A.T.
cd L.P.A.T.
python3 phonefree_lang.py templates/60min.detox
```

**Risultato**: Vedrai un timer virtuale che simula il tuo impegno. (Il vero blocco? Viene dopo, su veri device.)

## 💡 Che cos'è L.P.A.T. Davvero?

1. **Un DSL (Domain-Specific Language)** basato su Lark
   - Non Turing-complete (= niente loops infiniti che ti intrappolano)
   - Dichiarativo (= dici *cosa* vuoi, non *come* farlo)

2. **Un interprete Python** che valida e esegue regole sicure

3. **10+ template pronti** da usare e condividere

4. **Una comunità** che si aiuta reciprocamente a disconnettere
