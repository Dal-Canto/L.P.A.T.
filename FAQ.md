# ❓ Domande Frequenti su L.P.A.T.

## Generale

### D: Che cos'è L.P.A.T.?
**R:** Un linguaggio di programmazione (DSL) che ti aiuta a scrivere regole di digital detox in modo consapevole e trasparente. Non è un'app di blocco, è uno strumento educativo.

### D: Non è solo un'app di blocco come le altre?
**R:** NO. Le app di blocco tradizionali:
- ❌ Ti fanno sentire controllato
- ❌ Puoi bypassarle
- ❌ Non insegnano nulla

L.P.A.T.:
- ✅ Tu scrivi le regole (hai il potere)
- ✅ È trasparente (testo umano, non "black box")
- ✅ Impari programmazione nel processo
- ✅ È condivisibile (accountability)

### D: Quanto costa?
**R:** GRATUITO. È open source (MIT License). Sempre gratuito, sempre sarà.

### D: Che dati raccoglie?
**R:** NESSUNO. L.P.A.T. è locale. I tuoi file `.detox` rimangono sul TUO device. Niente cloud, niente tracking, niente azienda che vende i tuoi dati.

## Per Adolescenti

### D: Come uso L.P.A.T.?
**R:** 
```bash
git clone https://github.com/Dal-Canto/L.P.A.T.
cd L.P.A.T.
python3 phonefree_lang.py templates/60min.detox

Oppure scrivi il tuo file .detox seguendo gli esempi.

D: Posso condividere il mio programma con gli amici?
R: Sì! I file .detox sono testo semplice. Condividili via WhatsApp, email, Discord. Gli amici possono usarli come base per i loro.

D: Che succede se "barretto" il mio programma?
R: Dipende dalla tua coscienza. L.P.A.T. non è un blocco forzato sul device (non ancora). È una promessa che tu stesso scrivi. Se la rompi, sei solo con te stesso.

Ma la bellezza è: se la comunità vede che tradisci la tua promessa, perdi credibilità. L'accountability vero viene dalla gente che ti importa, non da un'app.

D: Devo saper programmare per usare L.P.A.T.?
R: NO! La sintassi è semplicissima:

program: study_time
duration: 60min
apps_blocked: [instagram, tiktok]

Non è Python o JavaScript. È umano.

D: Quanto tempo ci vuole a scrivere un programma?
R: 2-5 minuti. Basta copiare un template e modificare i parametri.

Per Genitori
D: L.P.A.T. è uno strumento di controllo dei genitori?
R: NO! Anzi, è il contrario. L.P.A.T. mette il potere nelle mani del ragazzo. Tu (genitore) non hai accesso speciale, niente "admin mode". Tuo figlio controlla tutto.

D: Come lo aiuta a staccarsi dal telefono?
R:

Consapevolezza — Scrivere le regole lo rende consapevole del problema
Accountability — Può condividere il suo impegno con te
Motivazione intrinseca — Sceglie lui (non è forzato)
Educazione — Impara programmazione nel processo
D: Posso monitorare quello che fa?
R: Solo se tuo figlio SCEGLIE di condividerlo. Apre il file .detox, te lo mostra, e tu vedi cosa si è impegnato a fare. Niente spyware.

D: Non è troppo complicato per un adolescente?
R: NO. La sintassi è semplicissima. Se riescono a fare TikTok, riescono a usare L.P.A.T.

Tecnico
D: Che linguaggio di programmazione usa L.P.A.T.?
R: Python 3.8+ con Lark (parser generator). È open source, quindi puoi controllare tutto il codice.

D: Come è sicuro?
R:

Non è Turing-complete (no loop infiniti, no runtime arbitrario)
Niente "backdoor" per genitori o aziende
Trasparenza totale (il codice è pubblico)
Validazione rigorosa (app_blocked è verificato)
D: Dove vanno i dati?
R: Da nessuna parte. I file .detox rimangono sul tuo computer/phone. Niente cloud, niente server, niente raccolta dati.
