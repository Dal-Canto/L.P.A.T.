# L.P.A.T. - Guida all'Installazione ed Esecuzione (Installation Guide)

Benvenuto in **L.P.A.T.**! Di seguito trovi le istruzioni dettagliate per scaricare e avviare l'applicazione già pronta su **Windows**, **Linux** e **macOS**.

---

## 🪟 Windows

Su Windows l'applicazione è già pronta e non richiede l'installazione di Python o di componenti aggiuntivi.

### Come avviarlo:
1. Scarica il file `launcher.exe` presente all'interno di questo repository.
2. Fai doppio clic sul file `launcher.exe` per avviare immediatamente il programma.
*Nota: Al primo avvio, Windows SmartScreen potrebbe mostrare un avviso di sicurezza. Clicca su "Maggiori informazioni" e poi su "Esegui comunque" per procedere.*

---

## 🐧 Linux 

L'eseguibile per Linux è un file binario singolo pronto all'uso, generato tramite compilazione nativa.

### Come avviarlo:
1. Scarica il file `launcher` dalle Release o dai reperti (Artifacts) di GitHub.
2. Apri il terminale Linux nella cartella in cui hai scaricato il file.
3. Concedi i permessi di esecuzione al file digitando:
   ```bash
   chmod +x launcher
   ```
4. Avvia l'applicazione:
   ```bash
   ./launcher
   ```

---

## 🍏 macOS (Apple Silicon M1/M2/M3)

Per il Mac l'applicazione è presente direttamente come cartella di sistema.

### Come avviarlo:
1. Scarica l'intera cartella **`launcher.app`** da questo repository sul tuo Mac.
2. **Primo avvio (Sblocco sicurezza Apple):**
   * Fai **click destro** (o tieni premuto `Ctrl` e clicca) sull'icona della cartella `launcher.app` (che sul Mac apparirà come l'icona di un'applicazione).
   * Seleziona **Apri** dal menu che compare.
   * Nella finestra di avviso di sistema che si apre, clicca nuovamente su **Apri**.
3. Per i successivi utilizzi, ti basterà fare un normale doppio clic per avviare il programma.
